Flatpak installs update from Brevier's own repository; the command line comes as one file; find and copy reach into tables.

**Flatpak installs update.** At the time, Brevier had a signed Flatpak repository that delivered updates after installation. That distribution channel is no longer maintained.

**The command line alone, one file.** The upstream release carried `brevier` by itself, with nothing to install beside it: no GTK, no OpenSSL. It included builds for Linux on x86_64 and on 64-bit ARM, macOS, and Windows. The macOS file was not signed; if it was downloaded with a browser, the quarantine attribute had to be removed once.

**Find and copy reach into tables.** Find on page now also finds words in table cells. It marks the match in its cell and brings the cell into view, in the window and on the phone. Copying a selection that contains a table now puts the table in its place as rows of tab-separated cells, which a text editor or a spreadsheet takes as they are. Before, the table was left out. In the window, a match after an image, a table or a formula used to be marked one character to the left; that is fixed.

**A waypoint's place on the shelf.** A waypoint, a paragraph start that stands in for a heading, now shows its place in the text at the right, "40%", like a page number in a book's contents. How much of it you have read is still shown by the bar.

**A site's menu without the repeats.** Some labels stand at four or more different addresses, such as "Comments" under every card on Habr's front page, "Read more" or "weiter". These are buttons on the cards, not menu items, and they no longer fill the site's pages on the shelf. A section repeated in the header, the footer and the mobile menu shows once. The limit of 60 rows now counts after these, so it no longer pushes real menu items out.

Files: `brevier.flatpak` (any distribution, with Flatpak; updates from Brevier's repository), `brevier-0.15.0-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.15.0-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key; it installs over earlier versions), `brevier-0.15.0-windows-x86_64-setup.exe` and `brevier-0.15.0-windows-x86_64.zip` (Windows 10 and 11, 64-bit), the command line alone: `brevier-cli-x86_64-linux.tar.gz`, `brevier-cli-aarch64-linux.tar.gz`, `brevier-cli-macos.tar.gz` and `brevier-cli-windows-x86_64.zip`, and `SHA256SUMS`.
