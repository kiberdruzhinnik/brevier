# Proposal

## Why

Public folder listings from Cloud Mail and Yandex Disk show each entry as a large heading. These entries are navigation links, so they should be readable at the regular text size.

## What Changes

- Render links in Cloud Mail and Yandex Disk public folder listings at the regular text size.
- Keep the folder title and other feed entry headings unchanged.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `public-cloud-shares`: Public Cloud Mail and Yandex Disk folder entry links use regular text sizing.

## Impact

The existing public cloud folder listing conversion path and its behavior specification. No API or dependency changes are expected.
